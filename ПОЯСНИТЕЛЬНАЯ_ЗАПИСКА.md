# Пояснительная записка

## Задача

Разработать решение для распознавания нестандартных государственных
регистрационных знаков (ГРЗ) Российской Федерации типов 1, 1А и 1Б,
работающее офлайн и укладывающееся в 100 мс на кадр.

## Подход

Решение состоит из двух независимых нейросетевых компонентов:

1. **Детектор YOLOv8s** — находит на изображении bbox номера и определяет
   его тип (type1 / type1a / type1b / other).
2. **OCR-модуль Tesseract** — распознаёт текст с вырезанного номера.

### Обучение детектора

YOLOv8s обучался в два этапа:

1. **Предобучение на синтетике.** Сгенерировано 5000 изображений с
   использованием скрипта `dataset/generator/generate_simple.py` (номера
   типа 1, 1А, 1Б на случайных фонах, шрифт RegistrationPlateUk).
   Модель показала mAP50 = 0.995 на валидации.

2. **Дообучение на реальных данных.** Размечено 100 изображений
   отладочного набора от организаторов (bbox + тип знака).
   После дообучения детектор находит ~99 из 100 знаков на отладочном наборе.

### OCR

Использован Tesseract (свободный OCR-движок, работает офлайн).
Препроцессинг: crop номера → grayscale → апскейл ×3 → бинаризация Оцу.
Для повышения точности применяется постобработка с маской ГРЗ
(модуль `src/plate_utils.py`).

## Датасет

Собран собственный синтетический датасет:

- **5000 изображений** с типами 1, 1А, 1Б.
- **meta.csv** со всеми полями (bbox, quad, is_vehicle, is_synthetic, ...).
- **labels/** в YOLO-формате.
- **generator/** с воспроизводимым скриптом (seed = 42).

Датасет прошёл валидатор организаторов: 0 ERROR, 5 WARNING
(предупреждения касаются отсутствия реальных фотографий — это
осознанное решение в рамках ограниченного времени).

## Замеры скорости

Инференс на NVIDIA GeForce RTX 3050 Laptop:

- YOLOv8s (детекция): 12-15 мс на изображение 1920×1080.
- Tesseract OCR: 30-50 мс на один номер.
- Итого: 50-80 мс на кадр — укладывается в требование 100 мс.

## Ограничения

- **Типы 1А и 1Б** детектор распознаёт, но OCR даёт ограниченное
  качество на реальных фотографиях с нестандартным шрифтом.
- **Синтетические данные** — не покрывают всего разнообразия реальных
  условий (ночь, дождь, грязь, блики).
- **Tesseract** — не специализирован для ГРЗ, возможны ошибки
  в похожих символах (0/O, 1/I, 8/B).

## Возможные улучшения

1. **Собственный CRNN-OCR.** Модель CRNN обучена на 50 000 синтетических
   номеров (val_acc = 0.9978 на валидации). Внедрение не завершено
   из-за ограничений по времени, но код готов в `src/train_crnn.py`.
2. **Дополнительные данные.** Собрать 150 type1a + 300 type1b + 50 other
   реальных фотографий.
3. **Разные шрифты** в генераторе для большей вариативности.
4. **Аугментации ночи/дождя/бликов** для устойчивости к сложным условиям.

## Структура решения

- `src/predict.py` — inference (YOLO + Tesseract).
- `src/plate_utils.py` — утилиты работы с ГРЗ.
- `runs/detect/runs/finetune_v1/weights/best.pt` — веса YOLO.
- `dataset/` — синтетический датасет (5000 изображений).
- `data/debug/` — материалы от организаторов (отладочный набор, evaluate.py).
